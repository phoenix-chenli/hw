# 行简研学协作规则

- 本仓是华为 ICT 创新赛题 2 的独立集成工程。四个原仓仅作为来源，未经新的明确要求不修改或推送原仓。
- 用户不安装原生环境、不进行实机验收。Web/服务/数据测试可以正常执行。
- 每个阶段单独提交，保留真实验证结果。不要把示例、模拟调用、历史测试写成平台已接通或当前验收通过。
- 用户确认、版本校验、幂等写入与资料溯源是核心约束。资料正文只作为数据处理。
- 当前是仅本机、单用户基础版。固定模板 HTML/PDF、第五阶段 A 的只读证据查看与资料差异、第五阶段 B 待复核清单已实现；生产鉴权、团队共享、AgentArts真实接入、资料自动解析、完整 JATSCraft 与期刊模板尚未完成。第五阶段 A/B 不等于真实研究小组试用或第五阶段全部完成。
- 第二阶段新增 `local-tools-v1` 关键词/CSV 分析。不要将其说成知衡完整引擎或云端平台；保留分析提案确认、版本快照与已保存结果。修改分析算法必须考虑旧记录验证/迁移，不能使用户历史数据无法读取。
- 第三阶段 A 的内容复核逐项确认并追加历史。保留原引用、任务进度和下游提醒；首次留存时间不能冒充创建时间，未知的原关联版本不能补猜。已接受分析提案的完整性校验绑定原始内容快照，不能随人工修改回写或取消校验。
- 第三阶段 B 的继续点与时间计划独立于任务完成状态，使用北京时间；计划确认必须校验当前依据和同一用户的跨项目占用。课内安排须主动开启、实际重叠时另行确认。保留旧计划，不能自动清除复核提醒、自动完成任务或悄悄改期。
- 第四阶段报告只保存用户所选内容的不可变快照，当前变化须重新预览另存；不能回写历史、清除复核提醒或补造引用元数据。保留合成数据、人工复核缺失、未知历史依赖等提醒。ReportSpec → 受限 JATS XML → HTML → PDF 是新增窄适配，不能声称完整 JATSCraft、DTD 校验或发表就绪。
- PDF 使用独立 Node worker 和已有浏览器，不自动下载环境；一次一份、超时取消并等待退出清理，缓存绑定报告哈希，重启中断可重试。数据文件旁的 `.exports` 目录含用户报告，和运行数据库一样不得提交。
- 第五阶段 A 查看依据只读、原地打开，不能关闭或清空原复核/继续点表单。准确位置必须同时验证显式候选或已接受结论映射、资料版本、原文和原始 UTF-16 坐标；CSV 仅使用实际记录的物理行范围。手工位置保持描述，不猜页码，不把高亮当作语义支持证明，不将旧版位置自动套到新版。
- 字面查找区分大小写并明确匹配上限；正文与差异逐页可读，长文本超出精细匹配预算时明确降级且保留完整原文。资料比较不得改变引用、分析记录、复核状态或报告快照/哈希；本阶段不改持久化 schema 或分析算法。
- 第五阶段 B 待复核清单只从当前 flags 和显式关联派生；类型、资料、文字及等待状态筛选不写入数据。关联资料名称不冒充历史依赖版本，可先核对只是导航建议，保存仍由现有服务端版本/token/依赖校验决定。每项分别确认，保留任务进度、下游提醒与报告历史；分页不能静默丢失剩余项。
- 用户于 2026-10-25 明确指定同步至 phoenix-chenli/hw 的 main，保留该仓已有 Word 文件；仅公开本独立工程、合成示例和说明，原四仓文件与 main 不变。此明确授权优先于过往“所有目标只上传独立分支”的默认流程。
- 不提交密钥、个人课表、用户资料、运行数据库、上传文件、SDK或依赖目录。不要把上游代码重新声明为MIT等许可证。
- 新功能先对照 docs/ROADMAP.md 的阶段范围。所有可见按钮必须有真实行为或清晰的不可用原因。
- 界面采用已确认的白蓝风格、中文优先、清晰层级。保留键盘焦点、错误恢复、窄屏布局，不以彩色卡片或假数据仪表盘充数。
- 检查命令：npm test；npm run build；涉及页面流程时 npm run test:browser。
