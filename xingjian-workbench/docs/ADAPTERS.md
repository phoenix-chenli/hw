# 外部能力与本地适配边界

本工程新增共同对象、确定性变更追踪、本地分析与固定模板导出，不复制四仓运行目录，也没有加载旧密钥、历史会话或真实校园资料。下列名称是本工程适配范围，不是声称华为官方已存在的 API；真实云端能力仍待接通。

第二阶段增加了 `local-tools-v1` 本地分析实现：关键词摘录、CSV 列聚合和版本化提案。其 `sourceRevisions`、`contextRevision`、定位精度和确认时版本校验，参考来源基线中知衡 `answer_contract.py` 的 `_location`/`evidence_graph` 与 `product_api.py` 的 `scope_current` 边界。没有复制这些文件、载入知衡服务、迁移向量模型或声称与 `answer.v6` 兼容。窄接口定义见 `phase-02-contract.md`。

| 适配对象  | 最小输入与结果                                       | 必须保留的边界                                                      |
| --------- | ---------------------------------------------------- | ------------------------------------------------------------------- |
| AgentArts | 服务端可信身份、项目范围、目标 → 结构化提案与运行 ID | 真实发布应用；密钥不下发；模型不能调用最终用户确认                  |
| 知衡      | 项目限定资料版本、问题 → 依据定位/受控计算/结论/缺口 | 保留 source_revisions 与 context_revision；未知定位不补造；表格只读 |
| 行简      | 已确认工作项、时间范围 → 计划预览与确认回执          | 提案和最终写入分开；确认时版本检查和幂等；课内重叠明确提醒          |
| 知途      | 统一任务 ID、用户进展 → 继续点与作品关联             | 不迁移浏览器随机令牌为团队身份；时长不等于完成；记忆需同意          |
| JATSCraft | 受限版本化 ReportSpec → JATS 子集 → 独立排版任务     | 不直接把 JSON 填入 DocumentIR；固定模板；源版本与产物版本可追溯     |

前端实际接口见 `phase-01-contract.md`。本地身份 `local-user` 只用于单用户本机，后续必须通过真实身份上下文替换。不要通过删除 Host/Origin 限制将基础服务暴露公网。

## 来源与许可

`source-baseline.json` 记录了实际核查的提交、可见性和复用约束。本工程是新增集成基础代码，未整包迁入原四仓。核查未发现四仓根目录的整体项目许可证；第三方许可证不等于项目整体授权，不给旧代码重新声明统一开源许可。

2026-10-25 用户明确指定将本独立工程同步到公开的 `phoenix-chenli/hw` main。只同步独立代码、合成示例与工程文档，保留来源记录；不复制四仓私有源码、用户资料、运行数据或原仓 Git 历史。来源基线是历史检查记录，不表示原四仓也已公开或授予统一许可。后续若引入原文件，仍需逐模块记录来源、作者与许可。

第三阶段 B 已增加本地继续点及确定性时间安排。它们分别遵循知途的“时长不等于完成”、行简的“预览/确认分离、过期校验、课内提醒”边界，未接入原服务或 AgentArts。实现契约见 `phase-03b-contract.md`。

## 第四阶段：受限成果适配

已新增固定模板 `ReportSpec`、不可变报告历史、受限 JATS 1.3 标签 XML、真实 XML → HTML 转换与独立 PDF worker。通过 `@xmldom/xmldom@0.9.12` 解析 XML，`playwright-core@1.61.1` 调用已有 Chrome/预配置 Chromium 打印；HTML 与 PDF 使用同一份已保存快照。不会把 JSON 直接塞入旧引擎的 DocumentIR，也没有复制上游完整排版服务。

目前只支持本工程白名单标签、属性、层级和固定研究进展模板。拒绝外部资源、DTD、处理指令、自定义实体和不受支持的格式；没有完成 JATS DTD 验证、上游全功能兼容、期刊模板或投稿规范验收。资料题名、引用版本、定位和哈希来自实际记录，缺少的作者/日期/DOI 保持缺失。

PDF 是本机独立 Node 任务，保留失败状态和历史产物；没有安装原生 SDK/浏览器，也没有 AgentArts 或模型调用。数据文件与 `.exports` 缓存仍为用户本地内容，不进入公开同步。字段与资源限制见 `phase-04-contract.md`。
