# 逐项复核契约

## 版本与兼容

沿用工作区 schema 1；结论、任务、草稿可选新增 `revisions`。没有复核过的旧数据不被静默迁移。第一次复核保存 v1 原始内容、追加 v2 用户确认内容；后续只追加，版本号连续。每版包含 `number`、`recordedAt`、非空 `reason` 和该类对象的内容字段。

v1 的时间是首次留存时间，不是原创建时间。原创建时间与旧任务/草稿当时关联的结论版本未记录，分别明确说明、保留 `claimVersions: null`，不能反推。

- 结论版本保存 `text`、完整 `evidence`，包括来源 ID、资料版本 ID 和定位描述。
- 行动版本保存 `title`、`claimIds`；复核后的版本另存 `claimVersions: [{claimId, version}]`。
- 草稿版本在行动内容字段之外保存 `content`。
- 待复核标记与任务完成状态是当前运行状态，不作为历史正文。复核行动不修改任务进度。
- 历史记录中的资料/结论版本必须存在，最新内容必须与最后一版一致。历史展示按记录的结论版本解析正文与证据，不替换为最新结论。

已接受的分析提案保持不可变。原候选与入库结果的一致性检查绑定初始内容快照；人工复核不改写旧提案，不取消原始内容完整性检查。

## 只读预览

`POST /api/review/preview`

```json
{ "projectId": "...", "kind": "claim", "entityId": "..." }
```

`kind` 为 `claim`、`task` 或 `artifact`。服务从本机身份解析用户，校验项目归属；对象必须待复核。返回 `baseVersion`、`reviewToken`、原内容 `baseline`、`sourceComparisons`、`claimComparisons` 和 `blockedBy`。预览不写入数据。

`reviewToken` 是原内容和当前依赖快照的 SHA-256，用于判断预览是否过期，不是登录令牌。依据包含当前资料版本、关联结论版本和复核状态。任务进度独立，因此不会被内容复核回滚。

## 单项确认

复用 `/api/commands` 的 `operationId`、`expectedRevision`、原子持久化和持久幂等回执。新增 `review_claim`、`review_task`、`review_artifact`。

共同 payload：`projectId`、`entityId`、`baseVersion`、`reviewToken`、`reason`。再按类型传入：

| 类型 | 可修改字段                  | 保留约束                                                       |
| ---- | --------------------------- | -------------------------------------------------------------- |
| 结论 | `text`、`evidence` 中的位置 | 保留原有全部来源，不增删来源；每条引用必须是该来源当前资料版本 |
| 行动 | `title`                     | 保留 `claimIds` 与当前进度                                     |
| 草稿 | `title`、`content`          | 保留 `claimIds`                                                |

关联结论尚待复核时，行动/草稿不能确认。结论确认只解除本结论标记，并使关联行动/草稿保持待复核；它们必须分别确认。允许原文不变，但仍需说明原因并产生可追溯的新版本。

主要错误：无权访问或对象不在项目内为 404；无待复核状态为 `REVIEW_NOT_REQUIRED`；预览过期为 `REVIEW_STALE`；依赖未处理为 `REVIEW_BLOCKED`；内容或历史格式不合法为 400。工作区整体过期仍遵循原有 409 版本冲突。任何失败不写入半成品。

## 交互恢复

预览失败可重试；409 时保留填写，刷新工作区并要求用户重新对照、重新勾选确认。旧输入不能自动覆盖新状态。网络响应丢失时复用原命令与操作 ID，服务重放原回执，避免重复追加版本。用户修改输入后视为新操作。

不同对象分别确认；取消仅关闭窗口，不写入。取消后未保存输入不跨窗口保留。草稿/任务历史可查看当时结论及资料，无法知道的旧依赖明确显示未知。

## 本阶段不包含

自动判断结论真假、全文语义影响发现、关系编辑、历史分析自动重算、计划生成、真实 AgentArts/模型调用、多人协同或公网部署。当前 Host/Origin、本机客户端头和项目范围校验继续生效，它们不等同于生产身份体系。
