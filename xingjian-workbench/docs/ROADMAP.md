# 行简研学实施路线

以 2026-10-24 新仓第一阶段为本仓编号起点。原 Word 中的 P0/P1/P2 是技术依赖拆分，不能按同一序号当作已经验收。当前第一阶段、第二阶段本地部分、第三阶段 A 逐项复核及 B 任务推进、第四阶段固定模板报告、第五阶段 A 证据定位与差异及 B 待复核清单已实现；用户已确认「尚未开通，先完成本地部分」。真实 AgentArts 接入与线上部署仍未完成，完整 JATSCraft/期刊模板未接入。

## 第一阶段：独立基础与关系验证

建立独立私有仓、锁定四仓来源；实现统一对象、可操作 Web 工作台、本地保存、来源更新预览与确认；建立自动检查。证明同一资料、结论、行动和草稿可以建立可靠关系。

范围：手工输入、显式关联、单用户本机。不得把 mock、UI 或纯规则引擎说成真实 AgentArts。

## 第二阶段：真实平台与分析最小链路

**当前状态：本地部分已实现；云端部分待开通。** 已新增关键词检索、严格 CSV 聚合、版本化分析记录、选择确认与过期拦截，详见 `PHASE-02.md`。这些是遵循知衡证据边界的新实现，不是知衡完整检索引擎或 AgentArts 的真实接通。后续可先进行第三阶段的本地核查流程；AgentArts 正式接通仍是参赛必要待办，不能被本地工具替代。

1. 核实团队 AgentArts 账号、可用模型、调用预算与网络环境，密钥仅保存在服务端。
2. 先用一条只读工具验证 AgentArts 实际构建、编排、调用和运行记录。不把本机 localhost 当作平台可访问服务。
3. 将知衡检索/受控计算适配为窄接口，返回项目、来源版本、定位精度、结论和缺口。缺定位保持未知，不编造页码。
4. 平台输出先展示为提案；用户确认后转换为本仓对象。来源版本变化时拒绝直接入库。
5. 在增加公网访问之前完成真实身份、项目授权、工具鉴权、限额和持久存储迁移。模型参数不能决定用户身份。
6. 验收：真实调用日志对应界面结果，资料不足与工具失败分支可重现。未获模型调用预算时，只做不调用模型的契约测试。

## 第三阶段：核查与任务推进

**第三阶段 A：逐项复核已实现。** 对照新旧资料与关联结论，分别确认结论、行动和草稿；记录复核说明、内容版本和当时依据。资料再次变化会重新提醒；复核不改变任务完成进度，不一键抹除下游提醒。界面、冲突恢复与验证范围见 `PHASE-03.md`。

**第三阶段 B：本地计划与继续点已实现。** 保存真实任务下一步、进展、阻碍和资料版本入口；录入具体日期的课程与忙碌时段，先预览再确认时间块。复用行简“先预览再确认”和知途“记录真实继续点”的边界，新写本地接口，没有迁入原服务。允许显式课内安排并保留提醒；计划覆盖同一用户跨项目占用，取消保留历史。详见 `PHASE-03B.md`。

已验证：重复确认不重复写、过期计划重新预览、关闭重开能回到真实继续点。计划与继续点不会自动完成任务；本阶段没有计时器或推送提醒。学期课表导入、自动调整建议、拖拽改期和个人日历接入尚未实现。

## 第四阶段：固定模板成果

**当前状态：本地固定模板已实现。** 用户选择与排序草稿，先预览版本和提醒，再保存不可变报告。串起版本化 ReportSpec → 受限 JATS 1.3 标签 XML → 实际 XML 解析 → 离线 HTML → A4 PDF，支持旧版下载、相关内容变化提示、失效预览拦截和响应丢失重试。报告不自动改变研究结论、任务进度或复核状态。

PDF 放独立 Node worker，调用电脑已有 Chrome，不安装原生 SDK、浏览器或整套 JATSCraft。保留生成状态与缓存，失败/中断可重试，HTML 可独立下载。上游完整引擎、DTD 验证、期刊模板、可编辑 Word 和自动语义写作不在本阶段范围。真实验证及限制见 `PHASE-04.md`，接口见 `phase-04-contract.md`。

## 第五阶段：交互深化与研究小组试用

**第五阶段 A：本地证据定位与差异交互已实现。** 原地打开引用的固定资料版本，可返回未完成的复核或继续点填写。只对显式分析候选或已接受结论映射中能验证的原文与版本恢复准确位置；CSV 使用实际记录物理行范围，手工定位描述不猜页码。加入版本内字面查找、资料历史比较、更新预览和复核中的有界行差异；旧版引用不会自动搬到当前版，报告快照内容和哈希不变。细节与验证见 `PHASE-05A.md`。

**第五阶段 B：待复核清单已实现。** 首页集中显示当前待复核结论、行动与草稿，支持类型、资料、文字和处理顺序组合筛选、分页及依赖结论入口。保存后按最新标记更新剩余项，取消返回原入口，原入口消失时回到清单标题。只对当前显式关联进行排序，最终依赖、依据版本和保存校验仍复用现有服务；不自动确认、不改完成进度、不清除下游提醒。详见 `PHASE-05B.md`。

目前只完成交互深化的上述部分，没有开展真实研究小组试用，不能据此标记第五阶段全部完成。后续找 3–5 个真实课程研究小组验证资料更新/导师反馈场景，记录再次使用、核对成本、漏项和返工；根据实际观察继续改善失败恢复、键盘与窄屏体验，不增加无用途仪表盘。真实试用数据与结论需另行记录。暂不开展试用时，可继续准备使用任务和可复现演示，但不得生成虚构的试用结论。

## 完成品交付批次 A–H

2026-10-26 起按完成品目标补齐核心缺口，优先真实平台链路，已有阶段不重新计作新平台能力。

- **A 已实现：云端分析协议、运行记录与证据校验。** 新增独立固定资料快照、发送授权、状态事件、严格证据编号提案及人工确认；旧本地工具与历史不变。默认云端关闭，配置齐备仍待验证。详见 `MILESTONE-A.md` 与 `milestone-a-contract.md`。
- **B 已准备、真实验收未执行：** 已按官方运行时接口实现受限传输，提供工作流输入/输出约定、提示词和配置说明。等待本团队已开通平台、发布态应用、服务端凭据及明确预算后，用一次授权的合成材料核对真实执行记录。详见 `AGENTARTS-WORKFLOW.md`。
- **C 待实施：** 生产身份与项目授权、受控 HTTPS 服务、可靠持久化和备份、平台可调用的只读检索/计算工具。当前本机服务不能直接公开。
- **D 待实施：** 分析、规划与成果组织的真实平台协作。先建立清晰职责，再按需要使用平台控制器；不能将三个提示词或本地函数当作多 Agent 已完成。
- **E 待实施：** 有预览的资料导入、可追溯知识接入、资料更新后的修改建议；保持确定关系与模型建议的区别。
- **F 待实施：** 围绕导入、提问、核对、行动与报告统一 UI/交互，完成错误恢复及首次使用收口。
- **G 待实施：** 固定任务集、保留验收集和真实小规模试用，记录实际效果、耗时与成本，不用软件测试数量代替模型效果。
- **H 待实施：** 固定可复现版本、在线演示、平台配置、架构、评测与参赛材料，按当届最终要求验收。
